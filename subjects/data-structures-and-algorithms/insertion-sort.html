Insertion sort

Insertion sort keeps a sorted part at the left. Each pass takes the next value, the key, and holds it aside. Larger values in the sorted part slide one place to the right. Then the key goes into the free place. The binary version first finds the place of the key with binary search. Choose a version and an input. The bars slide as the values move.
