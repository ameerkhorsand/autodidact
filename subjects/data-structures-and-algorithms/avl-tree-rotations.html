AVL tree rotations

An AVL tree is a BST where, for every node, the heights of the two subtrees differ by at most 1. After each insert or delete, the code walks back up the path. It fixes the first node that is out of balance with one rotation, or two. Choose an example. Watch the nodes slide as the links change.
